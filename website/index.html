Set up once

Three small steps. Then forget about it.

The helper runs quietly after you sign in to Windows and waits for a matching VIT Wi-Fi network.

  1. 1

    Download and install

    Download the Windows installer from this project’s official GitHub Release and run setup.

  2. 2

    Save campus credentials

    Open Automate VIT WiFi from Start, enter your username and password, then select Save credentials.

  3. 3

    Leave automation enabled

    It starts when you sign in to Windows and responds after Windows joins a Wi-Fi name containing uppercase VIT.

Next time Windows joins a VIT Wi-Fi network, login happens automatically.Typical captive-portal login takes a few seconds after Windows connects to Wi-Fi.

Auto Connect does not make Windows join Wi-Fi. Windows handles that part.

Pro tip: In the Windows Wi-Fi list, open the VIT network you normally use and turn on Connect automatically. Windows will join it itself, then Auto Connect can sign you in.

Trust and security

Nothing leaves your PC.

Your password stays on your PC

It is stored in Windows Credential Manager, not on this website or any server.

No cloud account

No sign-up or separate online account. The app works entirely on your machine.

Open source

Anyone can inspect exactly what the project does on GitHub.

Good to know: This is an unofficial student-made tool and is not affiliated with VIT. It only automates the captive-portal login you would normally complete manually.

Seeing a Windows warning on first install?

Windows may identify a new unsigned app as an unknown publisher. Only continue if you downloaded the installer from this project’s official GitHub Releases page.

FAQ

Common questions

Will it work after I restart my laptop?

Yes, as long as automation is enabled and Windows reconnects to the VIT Wi-Fi network.

What if internet is already working?

The app checks first, shows a green status, and does not submit credentials to the portal.

Can I turn it off?

Yes. Open the app and choose Disable automation. That stops its background checks and automatic logins until you enable it again.

Which Wi-Fi networks does it handle?

Networks whose names contain uppercase VIT, such as L-VIT.

Does it send my password to a server?

No. It uses your saved credentials only to log in to the captive portal on your own device.
