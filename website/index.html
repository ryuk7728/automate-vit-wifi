How it works

It handles the one step Wi‑Fi keeps asking you to repeat.

No forced re-logins, no extra browser tab when the connection is already working.

01

Connect or auto-connect to your VIT Wi‑Fi network exactly as you normally would.

02

It signs in only when needed

Set up once

Three small steps. Then forget about it.

The app stays out of your way until Windows has joined a VIT Wi‑Fi network and needs captive-portal login.

1

Download and install

Download the Windows installer from this official GitHub release and run the setup.

2

Save campus credentials

Open Automate VIT WiFi from Start, enter your campus username and password, then select Save credentials.

3

Leave automation enabled

It starts quietly when you sign in to Windows and watches for a Wi‑Fi name containing uppercase VIT.

Next time Windows joins a VIT Wi‑Fi network, login happens automatically.Typical captive-portal login takes a few seconds after Windows connects to Wi‑Fi.

Questions, answered

The practical details.

Everything you need to know before installing.

Does it connect my laptop to Wi‑Fi?

No. Windows connects to Wi‑Fi; the app handles captive-portal login afterward.

Will it work after I restart my laptop?

Yes. If automation is enabled and Windows reconnects to the VIT Wi‑Fi network, the helper starts after you sign in to Windows.

What if internet is already working?

The app checks first, shows a green status, and does not submit your credentials to the portal.

Can I turn it off?

Yes. Open the app and choose Disable automation. That stops its background checks and automatic logins until you enable it again.

Which Wi‑Fi networks does it handle?

Networks whose names contain the exact uppercase text VIT.

Does it send my password to a server?

No. It uses your saved credentials only to log in to the captive portal from your own device.
